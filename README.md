# After Dark Scrabble — iPad GitHub Pages build

Upload all six files in this folder to the ROOT of a GitHub repository. Settings → Pages → Deploy from a branch → main → /(root). Open the published HTTPS URL in iPad Safari, Share → Add to Home Screen.

## How to play
Play Scrabble on the physical board. Tap the corresponding first square on the digital board, type the full word, choose direction, specify blank-tile positions if needed, review the score and optional adult bonus, then confirm to draw a challenge. Next Player advances automatically. Rules button explains gameplay.

## Notes
The app checks placement and computes main-word, premium-square, crossing-word and seven-tile scores, but **does not validate dictionary words**. All bonuses are optional and require mutual agreement. This is a 12-turn-per-player house-rule variant, not standard full-length Scrabble. Data stays in local storage on this device. Hosting via GitHub Pages makes the app publicly accessible.
